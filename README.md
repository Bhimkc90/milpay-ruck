# MilPay Ruck

MilPay Ruck is a military pay and benefits calculator designed to help service members estimate their compensation based on rank, years of service, duty status, location, and special entitlements.

## Features

* Military base pay calculations
* BAH and BAS estimates
* Federal, state, and local tax estimates
* Special pay support
* Years of service calculations
* Responsive web interface
* Profile management and saved user data

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

This project was developed to provide military members with a simple and accessible tool for understanding their pay and benefits.

## Future Enhancements

* Additional special pay options
* Leave and earnings statement integration
* Deployment support calculations
* Mobile-friendly enhancements
